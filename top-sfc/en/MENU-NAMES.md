# Tales of Phantasia in English: the shortened menu strings

The menus draw a string in a column of fixed width: 8 characters for the name of an item, a
piece of equipment, a spell, a monster or a title; 12 for a sword skill; 3 to 5 for most labels.
A longer string is cut off or runs into the one beside it, so `menu.txt` holds the string that
fits. This is what each one stands for.
